# 🚨 Multilingual AI Crisis Agent for Hospitality (Google Maps Reputation)

An production-ready, autonomous AI Agent engineered in Make.com designed to protect local SEO and restaurant reputation 24/7 without human latency.

## 💼 The Business Challenge
A single unanswered 1-star review can ruin a restaurant's Local SEO ranking and cost up to 30 potential guests. Hospitality businesses often suffer from long response delays when international tourists leave negative reviews in global languages (English, Japanese, Korean, French, Chinese, or Malay). 

## 🤖 The AI Agent Solution
This system replaces rigid automation with an **Autonomous AI Agent**. Instead of answering everything blindly, the AI evaluates the review's severity and dynamically decides which operational tool to trigger in **under 3 seconds**.

### System Workflow:
1. **Instant Ingestion:** Captures live Google Business Profile reviews via secure webhooks.
2. **Zero-Shot Language Detection:** The AI detects the reviewer's native language dynamically.
3. **Smart Budget/Crisis Filtering:** Automatically filters out 4-5 star reviews to eliminate unnecessary AI token spend, focusing 100% on damage control for 1-3 star ratings.
4. **Autonomous Action Selection (Function Calling):**
   - **Tool A (Telegram Alert):** Triggered ONLY if the AI detects severe operational/hygiene failures (e.g., food poisoning, bad staff, bugs in food) to alert the floor manager instantly.
   - **Tool B (Auto-Reply Engine):** Publicly posts a contextual, highly empathetic apology on Google Maps in the exact same language used by the guest.
